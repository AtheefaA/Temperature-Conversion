# 🌡️ Temperature Conversion

## 📌 Project Overview

This project is a simple Python application that converts temperatures between different units, such as Celsius, Fahrenheit, and Kelvin. It provides an easy way to perform accurate temperature conversions using standard mathematical formulas.

---

## 📐 Temperature Conversion Formulas

* Fahrenheit = (Celsius × 9/5) + 32
* Celsius = (Fahrenheit − 32) × 5/9
* Kelvin = Celsius + 273.15
* Celsius = Kelvin − 273.15
